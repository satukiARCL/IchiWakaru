# 整地鯖用整地支援テクスチャ
[たかさわかーる](https://github.com/Helium745/TakasaWakaru)にインスパイアされたテクスチャ  
![スクショ](screenshots/screenshot.png)  
Screenshot - 青い枠が本テクスチャ 掘る位置がわかります
# 特徴
- 掘り進める位置に枠を表示します
  - 折り返しでブロックを数えて掘り始める手間を解消します
  - 途中で横にズレても簡単に復帰できます
- 視認性がよいです 1方向に青,もう1方向に橙,交点に桃色を採用しました
- たかさわかーるとの併用も可能です
- 設定を変更すればあらゆるスキルに対応できます
# 前提Mod
[Continuity](https://modrinth.com/mod/continuity)
たぶんこれだけで動きます
また整地鯖のテクスチャが当たっているならばおそらく動きます
# 導入
1. [リリースページ](https://github.com/x256x/IchiWakaru/releases)よりテクスチャをダウンロードしてください
2. 複数のテクスチャがzipで圧縮されています 解凍した中身をリソースパックフォルダに入れてください
3. オフセットとは前後左右のズレのことです 最初の枠が壁に近すぎるなど整地範囲に合わないときはオフセット値の異なるテクスチャを適用してください(画像参照)  
![オフセット1](screenshots/offset1.png)
オフセット1
![オフセット2](screenshots/offset2.png)
オフセット2
# 設定
各.propertiesファイルを適宜調べながらheights,width,height,tilesあたりを変更してください  
heightsは開始高さ スキルの高さを指定するとよいです  
width,heightはリピート単位 スキルの幅を指定するとよいです  
tilesはリピート内のテクスチャの配置 各ファイルに全て同じ値を設定するとよいです
